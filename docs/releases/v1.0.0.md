# v1.0.0 - résumé bullets that must cite verified evidence

Every bullet this release produces cites a verified evidence record and
passes a grounding gate; a claim the evidence does not support is dropped
with its reason, never rewritten. Fabrication is something the system
measures and gates in CI, not something it promises.

## Highlights

- **The grounding gate.** Citation resolves and is current → no markup →
  every number supported → claim strength supported ("contributed" does not
  become "led") → NLI entailment ≥ 0.95 on the cited statements.
- **Evidence you can trust.** One write path; an edited fact becomes a new,
  unverified revision; a person verifies before anything can be cited.
- **Retrieval measured, not assumed.** Hybrid BM25 + bge-small with RRF and a
  cross-encoder rerank, with a published ablation.
- **Adversarial by default.** 34 prompt-injection payloads mapped to the OWASP
  LLM Top 10 2026, scored as if the model obeyed every one; a hardened prompt
  (`generate-v2`), a markup check, redaction before any external call, and a
  local-only mode.
- **A service.** JWT scopes and API keys, per-key budgets, rate limits, a
  circuit breaker, tenant isolation enforced by the ORM and by Postgres
  row-level security, and OpenTelemetry traces carrying tokens, cost,
  per-stage latency and the gate's verdict.
- **A UI that shows its work.** Inline citations, evidence on hover, and a
  word diff between each bullet and the evidence it cites.
- **A public demo** on Hugging Face Spaces: read-only, rate limited, and its
  samples replay real recorded drafts through the live gate with no model call.

## Known limitations

- Benchmarks use a synthetic career; the golden set's labels are one
  person's judgement (ADR-010).
- The claim-strength lexicon was written after seeing failures, so the
  verifier's 0% false accept is in-sample (ADR-008).
- Row-level security does not apply to a superuser connection; budgets,
  rate limits and the circuit breaker are per process (ADR-016, ADR-017).
