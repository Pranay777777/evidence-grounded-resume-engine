# v1.0.2 - demo forms work inside the Hugging Face page

- Clicking a sample on the Space page failed with "missing or invalid CSRF
  token": the page shows the app in a cross-site iframe, where the
  `SameSite=Strict` CSRF cookie is never sent.
- In demo mode the cookie is now `SameSite=None; Secure; Partitioned`; a browser
  that blocks it falls back to the Origin check. Outside the demo nothing changed.
- Measured results are unchanged - see [v1.0.0](v1.0.0.md).
